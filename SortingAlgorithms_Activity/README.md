5.Ang kalahian sa tulo ka sorting algorithm kay una ang pamaagi sa ilang pag sort, ang bubble sort kay magswap sa duha ka tapad nga numero ang sa Selection sort kay mangita og mga gamay na numero dayon ibutang sa unahan balik sa una mangita napud og gamay hangtud maplastar dayon ang insertion sort kay mangita gihapon og gamay sa wala pero imbis nga mubalik sa pinakauna ang index padayon og pangita ang index hangtud sa ma plastar ang array.

Reflection
1.Ang Bubble sort mag swap sa duha ka magkatapad nga numero kung dako ang wala og gamay ang tuo diha mahitabo ang swap.Ang Selection sort mangita sa pinakagamy nga numero ug ibutang sa pinakaunahan.Ang Insertion sort kay mukuha og numero og sulod ni siya pawala kung gamay nga numero ug ang dako hinay mupadulong tuo.Ang ilang Kalahian kay ang proseso sa pag compare ug pagusab sa mga numero. 

2.Sa tulo kay sorting para sa ako, ang insertion sort kay macompare rani sa pagdula og cards ug pagplastar sa mga numero dali rapod ang iyang proseso, kung sa code pud dili kaayo kumplikado.

3.Ang insertion sort ang mas paspas og proseso kay ang mga numero kay nakaarange na daan gamay nalang dayon iyang buhaton kung naay mga wla na plastar.

4.Kung mas mudaghan ang array kay mas madugay ang proseso sa tulo ka sorting, daghan sila og icompare labi na kung grabi bunkag ang array.
